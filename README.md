# Wicked Kricꓘetz Website

A custom business website created for **Wicked Kricꓘetz**, showcasing custom apparel, decals, vinyls, tumblers, and personalized creations.

This website was designed and developed to provide customers with:
- A professional online presence
- A gallery of completed work
- Easy contact and quote requests
- Mobile-friendly browsing

---

## ✨ Features

- Responsive mobile-friendly design
- Custom neon-themed UI inspired by the business logo
- Image slideshow gallery
- Service showcase section
- Netlify contact form integration
- Social media links
- Custom thank-you submission page
- Smooth hover animations and glow effects

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Netlify Forms
- Font Awesome Icons

---

## 📱 Responsive Design

The site is optimized for:
- Mobile phones
- Tablets
- Desktop browsers

Special attention was given to mobile layout and image scaling for a smooth user experience.
